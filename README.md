# AnalisisPruebasSaberPro2023



Este proyecto esta destino a analizar el desempeño de los estudiantes que realizaron las pruebas saber pro en el año 2023, enfatizando la posible relación del estado socioeconomico del estudiante y sus familiares con respecto al puntaje obtenido en las pruebas. 

Para este analisis, se usó python, principalmente la libreria PANDAS para el correspondiente analisis de datos además de la libreria MATPLOTLIB para la visualización de los datos por medios de graficas estadistica.

El dataset fue otorgado desde el portal web del ICFES para datos libres: https://www.icfes.gov.co/transparencia-y-acceso-a-la-informacion-publica/datos-abiertos/
